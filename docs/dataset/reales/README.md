# Datos públicos

Muestras públicas pequeñas o derivadas que aportan contexto. No son datos
operativos, no se insertan automáticamente en la base de demo y no se presentan
como demanda, inventario o rutas observadas.

Cada muestra documenta en su manifiesto y su README: fuente, URL, fecha de
descarga, licencia, transformación, conteos y SHA-256 del origen y del
resultado. Cuando el archivo original contiene identificadores personales,
tributarios, institucionales o de permiso, solo se conserva un agregado y el
original no se versiona.
