# Fuentes de las diapositivas v3

- `Oswald.ttf`: títulos y cifras (fuente variable).
- `OpenSans.ttf` y `OpenSans-Italic.ttf`: cuerpo de texto (fuentes variables).

Ambas familias son de Google Fonts, con licencia SIL Open Font License 1.1.

**Antes de presentar `pitch-v3.pptx`**, instalen las tres fuentes en el equipo del escenario: en Windows, clic derecho y luego «Instalar para todos los usuarios»; en Linux, cópienlas a `~/.local/share/fonts`. El PPTX no incrusta las fuentes. Sin ellas, PowerPoint las reemplaza y los textos pueden desbordarse. `pitch-v3.pdf` ya las lleva incrustadas y sirve de respaldo.
