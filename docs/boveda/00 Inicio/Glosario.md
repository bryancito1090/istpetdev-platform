# Glosario

| Término | Definición para nuestro sistema |
|---|---|
| Punto de servicio | Instalación de un cliente que consume y recibe insumos |
| SKU | Referencia de producto con unidad base definida |
| Lote | Cantidad de un SKU con identidad, origen y vencimiento si aplica |
| Unidad logística | Caja o agrupación física con QR; contiene líneas de lote |
| Stock disponible | Existencia utilizable menos reservas y material bloqueado |
| Reserva | Cantidad comprometida; no equivale a consumo ni despacho |
| Movimiento | Cambio contable de cantidad entre ubicaciones o por consumo/ajuste |
| Consumo | Salida por uso del producto en el punto |
| Merma | Pérdida confirmada; una anomalía no demuestra merma |
| Quiebre de stock | Demanda no satisfecha por falta de existencias |
| Cobertura | Días estimados que cubre el stock |
| Lead time | Tiempo hasta que un reabastecimiento esté disponible |
| Ventana de atención | Intervalo en que un punto puede recibir |
| FEFO | Priorizar lotes que vencen primero, cuando aplique |
| Cadena de custodia | Actores, tiempos y transferencias de una unidad/lote |
| POD | Prueba de entrega con cantidades y evidencia |
| CQRS | Separación de operaciones que escriben y que consultan |
| Outbox | Registro durable de trabajo por enviar |
| Idempotencia | Reintentar la misma operación conserva un único efecto |
| UUID v7 | Identificador temporal; no es credencial ni reloj de negocio |
| PostGIS | Extensión espacial; no reemplaza una red vial |
| SignalR | Canal en vivo; el historial durable vive en el backend |
| P0 / P1 / P2 | Flujo crítico, sistema de demo y madurez nacional |
| Baseline | Política tradicional documentada de comparación |
| Run / seed | Ejecución y semilla que permite repetir sus datos |
| ADR | Registro de una decisión de arquitectura |

Ver [[Modelo de datos]], [[Inventario y prediccion]] y [[Simulador y metricas]].
